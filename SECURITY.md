# Security Policy

## Supported versions

Only the latest commit on `main` (the deployed version) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/chrisgocode/contextus/security/advisories/new).
Include steps to reproduce, the affected area, and the impact you expect.

You can expect an acknowledgement within 7 days. Once the issue is confirmed,
a fix will be prioritized and you will be credited in the advisory unless you
prefer otherwise.
